# 离线缓存设计评审

打开 `index.html` 可对比四套独立布局；页面不依赖外部字体、图片或服务。

| 方向 | 设计重点 |
| --- | --- |
| A 原生轻盈 | 系统分组、小封面、底部主要操作 |
| B 封面画廊 | 大封面、图文网格、舒展的选集页 |
| C 紧凑清单 | 高信息密度、清晰的空间与任务状态 |
| D 暗色影院 | 暗色界面、沉浸封面、播放优先 |

iOS 缓存管理和缓存选择采用 A「原生轻盈」：本地封面卡片、分段切换、独立下载卡片和底部确认操作。
本地播放复用普通视频页，HTML 中的播放页仅保留为设计原型。

顶部可同步切换已缓存、缓存选择、下载中和离线播放四个场景，也可单独查看一个方向。
手机内支持选择分 P、切换画质、批量添加任务、暂停、按任务允许蜂窝、失败重试、
字幕语言切换、拖动到片尾停止、分组选集，以及带数量和空间提示的删除确认。

这是使用示例内容的交互原型，不下载或播放真实视频，不修改 iOS 应用。
页面下方可记录偏好并复制评审意见；偏好保存在本浏览器。

需要浏览器地址时，从仓库根目录启动：

```sh
python3 -m http.server 8896 --bind 127.0.0.1 --directory design/offline-cache
```

访问 `http://127.0.0.1:8896`。直接打开某套方案可加 `?design=a`、`?design=b`、
`?design=c` 或 `?design=d`；场景可追加 `#select`、`#downloads` 或 `#player`。

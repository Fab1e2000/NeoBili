# NeoBili icon · 2026

## Current production revision

White background with flat, theme-colored vector play shapes. Editable master: `LayeredPlay-white-master.svg`. Generated by `scripts/generate-app-icons.py` and compiled as native Icon Composer documents. No image generation was used for this revision, and there are no baked highlights, shadows, blur, or translucency in the SVG artwork. The system controls appearance effects.

The PNG concepts and earlier production previews below are historical; `A-white-inset-production.png` shows the current native rendering. Foreground artwork is reduced to 80% and recentered; the full 1024 canvas and system corner mask remain unchanged.

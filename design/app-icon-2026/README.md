# NeoBili icon · 2026

## Current production revision

A block "B" monogram modeled on PiliPala's logo: a white letter face with a thin theme-colored rim, extruded at 45° toward the lower left. The bowls are semicircles; the two counters show the theme color of the extrusion behind them. The mark (about 60% of the canvas) is one flat vector layer (the extrusion with the face cut out), so the white background shows through the letter. Editable master: `BMark-white-master.svg`; README preview: `BMark-production.png`. Generated by `scripts/generate-app-icons.py`; the extrusion path stored there is the exact sweep of the rimmed face. The system supplies Liquid Glass effects.

Production sources: `../../NeoBili/Resources/AppIcons/`. The default icon is
`NeoBiliIcon`; the other 23 are `NeoBiliIcon-<theme-id>`.

Regenerate through `scripts/generate-app-icons.py` when changing the mark or palette.
The SVG master and production preview describe the current design.

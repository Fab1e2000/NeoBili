# NeoBili v1.3.0 — 新图标与推荐体验升级

## 新图标

- 应用图标改为叠放的视频卡片与播放标记，各主题色图标同步更新。

## 推荐与浏览

- 新增推荐来源选择：移动端、网页、混合推荐。混合模式交错展示两路结果，并去除重复视频。
- 推荐来源在完全退出并重新打开应用后生效；移动端与混合模式需要当前账号的 App 授权。
- 简化标题栏样式，保留「随内容滚动」与「固定·切边」，移除顶部渐变模糊。
- 优化 UP 主空间页滚动与分页切换时的头部同步，减少不必要的页面更新。

## 视频播放

- 合集与分 P 列表打开时定位当前播放项；选择后保持列表展开，支持连续切换。
- 修复切换合集或分 P 时列表反复居中引起的跳动，保留当前浏览位置。
- 优化密集弹幕的绘制与资源使用，低电量或高温时减少弹幕绘制负担。
- 修正临时倍速在播放内核暂停或播放结束时的恢复处理。

## 设置与说明

- 精简设置页的常驻说明，将详细解释集中到使用手册，减少页面占用。
- 合并播放方式相关开关，保留必要的授权、错误与重新打开生效提示。
- 首次进入设备编号页面时增加 BUVID 提示：可尝试导入自己官方 App 请求中的编号；相同编号不保证推荐完全一致。确认后不再重复弹出。

## 稳定性

- 改进账号切换、请求取消和页面退出时的状态处理，避免旧请求结果干扰当前页面。
- 调整播放器、网络与缓存的依赖管理，补充回归测试。

## 已知问题

- 使用 AirPods 时，摘下耳机可能无法自动暂停视频，已记录为 [#15](https://github.com/Fab1e2000/NeoBili/issues/15)，本版本尚未修复。

本次构建号为 17。

## 安装

最低系统要求 iOS 26。发布后提供未签名 IPA，需使用自己的证书签名后安装；可用同页的 `SHA256SUMS.txt` 校验文件。

# NeoBili v1.3.0 — 相关视频修复与设备编号切换

## 修复

- 修复部分设备编号下视频详情显示“暂时没有相关视频”：详情接口未附带相关模块时，补取相关视频列表。
- 区分相关视频的空结果与请求失败，失败时提供重试；分页失败保留已加载内容。

## 新功能

- 设置 → 高级新增“设备编号”，可选择系统派生编号或随机编号。
- 每种模式保存并复用自己的编号，配套隔离设备登记与票据；切回原模式可以恢复原编号。
- 切换需从后台退出 App 后重新打开，账号登录保留。默认继续使用原编号。

## 直播体验

- 主播资料、简介和弹幕保持同页，去掉独立圆角卡片，与视频页布局风格一致。
- 统一关注按钮样式，扩大弹幕开关点击范围并改善浅色模式对比度。
- 增加弹幕连接中与空列表提示。

设备编号切换用于兼容性测试，不保证改善推荐质量或得到与官方相同的视频流。

## 安装

下载 `NeoBili-v1.3.0-unsigned.ipa`，使用自己的证书签名后安装。最低支持 iOS 26。
使用同页 `SHA256SUMS.txt` 校验文件。覆盖安装时保持签名配置及 Bundle ID 一致，以保留原应用数据。

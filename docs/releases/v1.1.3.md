# NeoBili v1.1.3 — 推荐流修正与三种标题栏样式

NeoBili v1.1.3（构建 11）改进推荐流分页与刷新，统一普通 Android 客户端身份，并新增标题栏背景选项。

## 新功能与改进

- 标题栏提供「随内容滚动」「固定·切边」「固定·渐变」三种样式，适用于推荐、搜索、收藏、历史和稍后再看。旧的固定设置保留为固定渐变。
- 关注与直播的标题、头像条或切换器始终固定，使用切边背景，不受标题栏设置影响。
- 修正 App 推荐分页：使用服务端游标，避免广告、无效卡片和本地过滤影响后续加载；失败重试保留请求位置。
- 根据服务端配置，在恢复前台、返回推荐页或关闭内容页时自动刷新；滚动、加载或显示弹层时不会触发，网页推荐继续使用手动刷新。
- 登录、推荐、反馈和直播统一为普通 Android 手机客户端身份，使用配套的登录与业务签名。
- 改进 Xcode 26 编译兼容性，并补充推荐、账号凭据迁移、标题栏设置及播放器过渡回归测试。

## 升级说明

旧 HD App 凭据不会发送给新的 Android 接口。升级后保留网页登录状态，并尝试换取新的 App 凭据；若失败，可在「设置 → 推荐流」中补充 App 授权。

客户端身份统一不保证推荐质量提升，已登录账号的服务端推荐效果仍取决于实际使用情况。

## 下载与安装

- `NeoBili-v1.1.3-unsigned.ipa`：Release 配置构建，未签名；安装前需要使用自己的证书或签名工具签名。
- `SHA256SUMS.txt`：下载校验文件，在同一目录运行 `shasum -a 256 -c SHA256SUMS.txt` 校验。

**系统要求**：iOS 26.0 或更高版本的 iPhone。

NeoBili 是独立的第三方项目，与哔哩哔哩无官方关联。

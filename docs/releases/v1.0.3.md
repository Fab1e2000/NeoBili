NeoBili v1.0.3，构建号 4。

### 导航与搜索
- 搜索集成到底部 TabView，修复退出搜索后顶部再次出现搜索框的问题。
- 修正搜索建议点击范围和键盘下方的背景覆盖。
- 直播标签移至推荐左侧，启动时仍默认进入推荐页。
- 移除页面底部的渐变模糊。

### 视频与直播
- 视频和直播共用底部缩略播放器，退出详情后继续播放；缩略播放器仅显示标题与播放操作。
- 调整缩略播放器长按菜单的预览与圆角，分离菜单预览和页面转场锚点。
- 统一视频与直播的缩放卡片转场及退出手势，调整快速进入后立即返回时的转场处理，不增加手势等待时间。
- 直播推荐/关注支持横向滑动切换；简化顶部标题，移除链接按钮与卡片直播状态角标。
- 加强直播卡片区分度，移除直播列表刷新提示浮层，保留下拉刷新。
- 调整直播弹幕区域底部间距。

### 详情与主题
- 收紧评论正文、操作与回复预览的间距，点赞和回复恢复普通按钮样式。
- 评论输入框仅在编辑时显示发送按钮。
- 推荐视频移出整体容器，合集与分 P 使用独立视频卡片。
- 使用白底叠层播放图标，并随 24 种主题色同步切换桌面图标。

### 安装
- 要求 iOS 26 或更高版本。
- `NeoBili-v1.0.3-unsigned.ipa` 使用 Release 配置构建，未签名；请使用自己的签名方式安装。
- `SHA256SUMS.txt` 用于校验下载文件。

本轮播放器修改已通过 26 项真机定向测试；发布包执行 Release 构建与包结构校验，未使用模拟器。

# NeoBili v1.2.1 — 评论交互、设置整理与浏览性能

## 新功能与体验

- 评论主列表、楼中楼预览和回复详情显示 IP 属地（接口未提供时不显示）。
- 视频评论中的 `02:35`、`1:02:03` 等时间可点击，跳到当前分 P 的对应进度；播放器未就绪或时间超出视频长度时给出提示。
- 评论链接优先显示服务端标题：普通 BV/av 链接在 App 内打开并保留返回路径，`b23.tv` 短链先解析再打开；其他网页和带分 P、时间参数的视频链接在内置浏览器打开，解析失败也回退到浏览器。
- 评论长正文可展开、收起；楼中楼可点击回复用户名或“查看全部回复”进入详情。
- 设置按外观、浏览、播放、账号、高级和关于重新分类：动画移到“外观”，播放器手势和控件位置移到“播放”，“浏览 → 内容过滤”集中提供全局与推荐过滤。调整不会重置已有偏好。
- 支持没有独立音轨的 DASH 视频，静音视频也能正常加载。
- 修正视频点赞操作。

## 修复与性能

- 图片缓存按访问顺序淘汰，命中与淘汰不再扫描全部缓存；评论表情合并加载，原图缓存设上限，长时间浏览评论不再无限占用内存。
- 日期格式化按模板、语言和时区复用，列表滚动时不再逐行重新创建。
- 搜索联想由搜索页自行管理，输入时不再触发根页面更新；提交、清空或发起新联想时丢弃旧结果。
- 资料库与“全部关注”对重复记录去重：历史按服务端游标继续加载，收藏按原始页长度判断末页；出现重复或被过滤的页时仍提供“继续加载”，失败可重试。
- 横向视频卡、相关推荐和直播卡的文字区域随字号增长，正常字号保持原布局。
- 收起视频画面时弹幕停止逐帧渲染，展开后跳过隐藏期间积压的弹幕；拖动预览复用缩略图，切换视频后旧视频的预加载不再混入。
- 直播弹幕粘包按偏移读取，不再为每条消息复制剩余数据；重连时保留仍有效的渲染关联。
- 空评论页不再重复请求首次加载。

## 安装

下载本页的 `NeoBili-v1.2.1-unsigned.ipa`，用自己的证书签名后安装。
可使用同页 `SHA256SUMS.txt` 校验文件。最低系统要求 iOS 26。

# NeoBili v1.3.1 — 原生标题、字体风格与统一刷新

## 外观

- 推荐、搜索、资料库、关注、直播改用系统原生大标题，头像入口移到导航栏右侧，下滑时导航栏自动收起（收起行为需 iOS 27）。移除「标题栏」设置项和顶部渐变模糊。
- 新增「字体风格」：默认字体或内置思源宋体（SIL OFL），中英文使用同一套衬线字形；重新打开应用后生效。

## 刷新

- 稍后再看、历史、收藏夹及其内容、UP 主空间的下拉刷新与推荐页一致：同样的下拉距离，旧内容淡出、新内容到了再换入，失败时保留旧内容。
- 收藏、历史、稍后再看的卡片支持进入和退出动画，可在「设置 → 动画」中分别开关；空间页支持刷新时的退出淡出。
- 从「我的服务」进入稍后再看、收藏、历史时，右上角增加刷新按钮；作为底部标签页挂载时不显示。
- 关闭系统下拉刷新转圈的隐藏，保留原生刷新提示。

## 视频页

- 评论层级与评论输入框（玻璃浮层）调整，评论元信息保持在同一行。
- 视频简介页更紧凑；合集与分 P 列表随内容展示。
- 标签行不再显示滚动条。

## 已知限制

- 导航栏自动收起仅 iOS 27 起生效，iOS 26 只有大标题。
- 宋体风格只内置 Regular 与 SemiBold 两个字重，字体中没有的生僻字回退为苹方。

本次构建号为 18。

## 安装

最低系统要求 iOS 26。安装包没有 Apple 开发者证书，只带 ad-hoc 签名。

SideStore 的 App 页只接受 IPA。点右上角的链接按钮，粘贴：

https://github.com/Fab1e2000/NeoBili/releases/download/v1.3.1/NeoBili-v1.3.1-unsigned.ipa

要在「源」页添加后安装和更新，使用：

https://cdn.jsdelivr.net/gh/Fab1e2000/NeoBili@main/sidestore/apps.json

软件源地址不是 IPA，贴进 App 页会提示「请提供一个 IPA 文件用于安装」。AltStore、Sideloadly 也可以用上面的 IPA 地址，或下载本页附件后用你的 Apple ID 重签。请用同页的 `SHA256SUMS.txt` 校验文件。2026-11-01 更换过安装包，旧校验和不再适用。

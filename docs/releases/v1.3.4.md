# NeoBili v1.3.4 — 直播、收藏与列表操作改进

## 直播与缓存

- 直播页顶部展示已关注且正在开播的主播，点头像即可进入直播间。下方可以直接浏览推荐直播。
- 缓存页顶部可切换「已缓存」和「下载中」。删除缓存或取消任务后，后面的卡片会自动补上空位。

## 收藏与评论

- 收藏夹以带封面的列表展示。点右上角按钮可新建收藏夹，长按自己创建的收藏夹可删除，删除后可短暂撤销。
- 修复长按菜单偶尔选中相邻卡片的问题。移除收藏、历史记录、稍后再看或自己的评论后，后续条目会补位。开启系统「减弱动态效果」时直接重排。
- 在回复详情顶部下拉即可关闭。评论中指向视频第一分 P 的分享链接现在可在应用内打开。
- 视频详情的「发弹幕」入口与旁边的分段栏对齐。

## 权限与软件源

- 移除了旧扫码登录所用的相册写入权限。登录继续使用短信验证码。
- SideStore 软件源使用新版应用图标，并展示该版本实际使用的权限。

本次构建号为 21。

## 安装

支持 iOS 26 及以上版本。下载附件 `NeoBili-v1.3.4-unsigned.ipa`，可用同页的 `SHA256SUMS.txt` 校验。通过 SideStore、AltStore 或 Sideloadly 使用自己的 Apple ID 重签安装。

SideStore 可添加[国内源](https://n015.top/neobili/apps.json)或[备用源](https://cdn.jsdelivr.net/gh/Fab1e2000/NeoBili@main/sidestore/apps.json)。

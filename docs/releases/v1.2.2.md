# NeoBili v1.2.2 — 自定义 BUVID 与视频页体验优化

## 自定义 BUVID

- 在“设置 → 高级 → 设备编号”填写并保存自己的 BUVID，退出并重新打开 App 后持续使用。
- 替换原来的系统派生／随机模式选择；留空时使用首次生成后固定保存的随机编号，不随刷新更换。清空自定义值可恢复原随机编号。
- 不同自定义编号分别保存设备登记、访客编号与票据，账号登录保持不变。
- 应用不预置任何人的官方设备编号。自定义 BUVID 提供设备身份的选择与排查入口，不保证所有用户的推荐效果都会改变。

- 统一 Debug 与 Release 的国际版 iPhone 请求配置，避免打包时恢复旧参数导致推荐表现回退。

## 视频页优化

- 优化播放器收缩与简介、评论列表的协作，减少滚动时反复改变列表尺寸带来的布局开销。
- 使用原生拖动与惯性滚动，改进简介／评论切换、顶部回弹及短列表的布局同步。
- 限制内容区的可见与点击范围，避免隐藏内容侵占播放器控件的触摸区域；统一评论加载占位和已加载列表的顶部空间。
- 视频和直播在前台播放时保持屏幕常亮，暂停、结束或离开前台时恢复系统自动锁屏。
- 避免仅打开应用或首页静音预览就抢占其他应用的音频；播放、暂停和关闭时更准确地管理音频会话。

## 稳定性修复

- 改进评论分页、视频详情失败重试，以及切换视频和分 P 后的返回恢复。
- 修正直播取流、小窗、休眠与弹幕任务在关闭或切换时的状态同步。
- 图片查看器改进加载失败后的重试、缩放与分享，并限制解码和缓存开销。
- 改进登录失败后的恢复，以及 App 授权被撤销后的提示；网络失败不直接判定为退出登录。
- 推荐过滤设置支持解除本机屏蔽的作者。

本次构建号为 15。

## 安装

下载本页的 `NeoBili-v1.2.2-unsigned.ipa`，用自己的证书签名后安装。
可使用同页 `SHA256SUMS.txt` 校验文件。最低系统要求 iOS 26。

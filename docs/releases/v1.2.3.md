# NeoBili v1.2.3 — 播放手势与视频页交互优化

## 播放手势

- 轻点画面显示或隐藏控件，双击暂停或继续播放，改进点击响应与拖动、长按之间的手势协调。
- 播放中按住画面 0.3 秒临时以 2× 播放，松手、取消手势或暂停后恢复原倍率。
- 音量手势使用播放器内的玻璃百分比提示；手势结束后恢复系统音量提示，手机音量键继续使用系统提示。

## 视频页交互

- 竖屏播放器从展开尺寸缩至紧凑尺寸时保留正常控件操作，播放和暂停切换保留当前尺寸。
- 仅在暂停后继续向控制栏收缩时，由展开按钮接管播放器区域的点击。
- 修正暂停收缩后评论顶部的裁切，改进评论与播放器收缩状态的协作。

本次构建号为 16。

## 安装

下载本页的 `NeoBili-v1.2.3-unsigned.ipa`，用自己的证书签名后安装。
可使用同页 `SHA256SUMS.txt` 校验文件。最低系统要求 iOS 26。

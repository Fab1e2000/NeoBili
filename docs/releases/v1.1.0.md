NeoBili v1.1.0（构建 8）带来**英文界面**、**重做的关注页**和**发弹幕**，并统一了各主页面的页头与导航。

## 亮点

- **English UI**：设置 → 外观 → 语言，可选跟随系统、简体中文或 English
- **全新关注页**：标题下方的横向头像条，红点与 B 站同步，正在直播一眼可见
- **发弹幕**：视频页与全屏播放器都能发，自己发的弹幕带绿色边框
- **导航可定制**：标题栏固定或随内容滚走；标签栏可排序、隐藏、选启动页

## 新功能与改进

### 英文界面

- 新增英文界面：设置 → 外观 → 语言，可选跟随系统、简体中文或 English，重新打开应用后生效。
- 跟随系统时，系统语言为中文显示中文，其它语言显示英文；B 站返回的标题、评论、热搜等内容保持原文。
- 英文界面沿用 B 站说法（UP、Danmaku、Coin 等），播放量等大数字显示为 K/M/B，相对时间与日期随语言变化。

### 关注

- 侧边头像选择器改为标题下方的横向头像条：「全部动态」在前，随后是直播中和最近有动态的 UP 主；轻点头像立即切换，动态淡出淡入。
- 新增「全部关注」页，每行五个头像，轻点进入 UP 主主页。
- 头像条红点与 B 站同步：点选有更新的 UP 主时清除红点，并按网页动态页的方式通知 B 站。

### 视频页与播放器

- 支持发送弹幕：视频页切换器右侧与全屏播放器中新增「发弹幕」，全屏时在横屏键盘上方显示输入栏；自己发送的弹幕带绿色边框。
- 全屏播放器控件避开屏幕圆角与灵动岛，上下边距统一，控件间距一致；新增全屏与非全屏的控件位置设置页。
- 简介与评论切换器改为顶部栏，内容从其下方滑过；UP 主、简介与相关视频改为更接近系统风格的排版。
- 内容区顶部使用更大的连续曲率圆角，播放器与内容区间距和切换器边距重新调整。

### 页面与导航

- 各主页面使用统一的页头（标题与头像），头像是「我的」的入口，「我的」改为标准底部卡片。
- 新增全局「标题栏」设置：随内容滚动或固定在顶部，推荐、直播、关注、搜索和资料库页面统一生效。
- 标签栏可调整顺序、隐藏标签、选择启动页；稍后再看、收藏、历史可作为标签页显示，标签栏最多 5 个（含固定在末尾的搜索）。
- 设置首页按外观、页面、播放、内容与交互、账号分组，每行直接显示当前值。

### 直播与搜索

- 直播页的推荐/关注切换器随「标题栏」设置与标题一起固定或滚走。
- 热搜改为一行一条，字号与推荐卡片标题一致；标题与搜索框位于同一顶部栏，随内容滚动时只收起标题。

## 问题修复

- 修复推荐卡片中含 emoji 的标题溢出到封面上的问题。
- 修复切换账号后资料库标签仍显示上一个账号内容的问题。
- 修复退出视频页后立即收缩标签栏时，缩略播放器错位压住搜索按钮的问题（系统问题，退出后 0.5 秒内暂不收缩标签栏）。
- 修复暂停视频收缩为标题栏后，主题色层压住下方白色内容顶部一条细横条的问题（构建 8 紧急更新）。

## 下载与安装

| 文件 | 说明 |
| --- | --- |
| `NeoBili-v1.1.0-unsigned.ipa` | 129.3 MB，Release 配置构建，**未签名** |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验值 |

1. 下载 IPA 和 `SHA256SUMS.txt`，在同一目录下运行 `shasum -a 256 -c SHA256SUMS.txt` 校验。
2. 使用你自己的开发者证书或常用的签名工具签名，然后安装到设备。

**系统要求**：iOS 26.0 或更高版本。

**验证**：离线回归套件全部通过。

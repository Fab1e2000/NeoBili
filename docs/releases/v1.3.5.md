# NeoBili v1.3.5 — DLNA 投屏、加载占位与播放体验改进

## DLNA 投屏

- 在线视频、直播间与离线缓存的播放器更多菜单均新增「投屏」入口，支持自动发现局域网内的 DLNA/UPnP 设备（无多播权限的自签环境自动回退同网段单播扫描），也支持手动输入设备地址并自动记住最近使用过的设备。
- 投屏以持久模式运行：开启后可离开当前页面继续浏览，底部状态条保留播控与退出入口；点播其他视频、离线缓存或直播间时自动将新内容切换到当前投屏设备。
- 在线点播通过本地实时无损混流支持全画质（含 1080P60 / 4K）与独立音质（含 192K / 杜比 / Hi-Res）热切换，直播支持清晰度热切换；点播与离线缓存支持进度拖动、音量调节及退出投屏后自动回接本地进度。
- 投屏期间横屏视频保持固定不收缩，竖屏视频最多收缩至默认横视频尺寸。

## 加载体验与前台优先

- 推荐页、视频简介、相关视频与评论（含回复详情）在首批加载期间展示卡片占位，减少空白等待。
- 改善各列表与详情页的内联加载失败提示与就地重试，手动刷新失败时保留已有内容。
- 在线播放或加载视频及直播时自动收紧离线缓存并发，优先保障前台播放与图片加载速度。

## 直播、收藏与交互细节

- 直播页顶部改为横向展示已关注且正在开播的房间卡片，分组标题随滚动吸顶。
- 收藏夹列表改用圆角分组样式并支持下拉刷新；历史、收藏与稍后再看的长按菜单命中更准确，简介下方推荐视频支持长按加入稍后再看。
- 优化离线缓存选集、楼中楼单条回复长按复制等细节交互。

## 权限

- 新增本地网络访问权限说明，用于发现局域网内的投屏设备及在本地转发投屏媒体流。

本次构建号为 22。

## 安装

支持 iOS 26 及以上版本。下载附件 `NeoBili-v1.3.5-unsigned.ipa`，可用同页的 `SHA256SUMS.txt` 校验。通过 SideStore、AltStore 或 Sideloadly 使用自己的 Apple ID 重签安装。

SideStore 可添加[国内源](https://n015.top/neobili/apps.json)或[备用源](https://cdn.jsdelivr.net/gh/Fab1e2000/NeoBili@main/sidestore/apps.json)。

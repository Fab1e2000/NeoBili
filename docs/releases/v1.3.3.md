# NeoBili v1.3.3 — 离线缓存与播放体验优化

## 离线缓存

- 支持缓存普通视频、多 P 和 UP 主合集，可选择画质并批量添加任务。
- 新增底部「缓存」页和「我的 → 离线缓存」入口，支持查看进度、暂停、继续、重试及批量删除。
- 默认仅通过 Wi-Fi 下载，可为单个任务确认使用蜂窝网络。
- 保存音视频、封面、弹幕及可用字幕；完成后可从「已缓存」离线观看，在线与离线分别记录播放进度。
- 缓存标签支持调整顺序、隐藏及设为启动页。

## 播放与界面

- 合集与分 P 列表打开时定位当前播放项，切换选集后保留列表位置。
- 修复无独立音轨的静音视频加载问题。
- 优化视频详情滚动衔接、内容布局及列表滚动指示器显示。

本次构建号为 20。

## 安装

最低系统要求 iOS 26。安装包带 ad-hoc 签名，可通过 SideStore、AltStore 或 Sideloadly 使用自己的 Apple ID 重签安装。

下载附件 `NeoBili-v1.3.3-unsigned.ipa`，使用同页 `SHA256SUMS.txt` 校验。

SideStore 软件源：[国内源](https://n015.top/neobili/apps.json) · [备用源](https://cdn.jsdelivr.net/gh/Fab1e2000/NeoBili@main/sidestore/apps.json)

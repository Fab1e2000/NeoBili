# NeoBili v1.1.1 — B 字图标与透明玻璃播放控件

NeoBili v1.1.1（构建 9）把图标换成**立体 B 字**，播放器控件改用**透明玻璃**，并调整了视频页操作和设置分组。

## 亮点

- **新图标**：立体挤出的 B 字，24 个主题色图标一起更新
- **透明玻璃播放控件**：画面透出来，控件出现时自动压暗，亮画面上也看得清
- **操作更快**：点赞、投币、收藏等轻点即执行；按住点赞 0.5 秒一键三连
- **设置重新分组**：外观、浏览、播放、高级、账号

## 新功能与改进

### 图标

- 主屏幕图标由立体 N 字改为立体 B 字：白色字面、主题色细边和向左下的挤出，两个字腔透出主题色。24 个主题色图标全部更新，深色与着色外观由系统生成。

### 播放器

- 播放器控件统一改用透明玻璃，让画面透出来。控件出现时画面整体轻微压暗，上下两排控件和中间的播放按钮背后再加深；控件隐藏后恢复原画面。出错时只在仍然显示的按钮背后压暗，错误提示保持原样。
- 时间文字加粗；拖动进度时的预览框和直播间的「重新连接」按钮也改用透明玻璃。
- 控件位置设置的边距改为按看得见的控件计算，调到 0 时控件正好贴边；拖动滑条时播放器控件实时重排。已保存的设置继续有效。

### 视频页

- 点赞、不喜欢、投币、收藏、分享改为轻点即执行（原来需要长按后松手）。按住点赞 0.5 秒一键三连，按住收藏 0.5 秒选择收藏夹（原来都是 1.2 秒）。
- UP 主的关注按钮改用液态玻璃样式，与 UP 主空间页一致。

### 关注

- 长按头像条里的 UP 主时，预览带圆角底板并显示完整名字，菜单可进入直播间或 UP 主主页。

### 设置与提示

- 设置首页分为外观、浏览、播放、高级、账号五组：内容过滤移到「浏览」，动画、播放器手势、播放器控件位置等细调项收进「高级」。
- 操作提示浮层改用系统玻璃，深色模式下也能和背景分开；使用 VoiceOver 时会播报提示内容。

## 下载与安装

| 文件 | 说明 |
| --- | --- |
| `NeoBili-v1.1.1-unsigned.ipa` | Release 配置构建，**未签名** |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验值 |

1. 下载 IPA 和 `SHA256SUMS.txt`，在同一目录下运行 `shasum -a 256 -c SHA256SUMS.txt` 校验。
2. 使用你自己的开发者证书或常用的签名工具签名，然后安装到设备。

**系统要求**：iOS 26.0 或更高版本。

**验证**：离线回归套件全部通过。

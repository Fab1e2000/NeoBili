# NeoBili v1.2.0 — 推荐体验、资料库与网络层升级

## 新功能与体验

- 首页支持服务端下发的大卡片和可见时静音预览，推荐理由使用黄色标记。
- 播放器支持倍速；稍后再看按服务端游标分页。
- 稍后再看、历史记录与收藏支持长按菜单进入多选，统一底部批量操作与撤销体验。
- 增加“刷新后保留上次数据”设置，默认开启；关闭后下拉刷新替换旧推荐。
- 搜索框聚焦时隐藏下方历史和热搜，输入后显示建议。
- 关注页头像点击切换动态，再点当前 UP 主进入主页，长按直接进入直播间。
- UP 主空间使用对应的背景图，支持深浅色背景选择。

## 修复与性能

- 修复首页刷新与翻页游标混用、过期响应影响刷新状态的问题。
- 修复直播推荐请求缺少显示缩放参数导致的 code -400。
- 修正大卡片标签、标题行数及播放前后的统计覆盖层，减少列表布局与预览播放器的重复工作。
- 降低逐事件 Keychain 读取和共享设置写入开销，预览播放器在停留及取流成功后再创建。
- 修复登录续期结果未及时反映到账户状态，以及观看时长在倍速下的编码差异。
- 修复资料库 Tab 入口的多选可用性与搜索头像动画。

## 网络层与维护

- 接入设备/访客登记、App 票据和登录凭据续期，使用自身账号和设备上下文。
- 推荐、点击、曝光及观看上报按已确认研究规则接入，并保留来源和账号代际约束。
- 网络代码按业务接口、传输、身份、推荐和上报分目录；增加文档导航及本机协议校验入口。

上述调整不承诺与官方客户端返回完全相同的视频。完整设备资料、部分业务字段和推荐效果仍有验证边界；设备管理显示登录记录也不等于所有设备字段均已验收。

## 安装

下载本页的 `NeoBili-v1.2.0-unsigned.ipa`，用自己的证书签名后安装。
可使用同页 `SHA256SUMS.txt` 校验文件。最低系统要求 iOS 26。

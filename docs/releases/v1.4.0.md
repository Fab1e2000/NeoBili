# NeoBili v1.4.0 — 评论区功能完善与推荐卡片补位

## 评论区

- 视频评论、动态评论和回复详情增加 UP 主标识，点击头像或昵称可进入个人主页，返回后保留评论位置和输入草稿。
- 展示置顶评论及「UP 主觉得很赞」「UP 主回复过」标记，置顶内容不再与普通列表重复出现。
- 支持「热门／最新」切换和下拉刷新；刷新失败时保留原内容，刷新不会清空输入草稿。
- 长按评论或回复可复制完整正文，包括折叠的内容；登录后可删除自己的评论，确认成功后同步更新评论列表、回复和计数。
- 采用轻量样式，并补齐英文文案和大字号布局。

## 修复

- 修复短信登录点击「获取验证码」后安全验证页空白的问题；验证加载失败或超时时提供重新加载入口。
- 修复推荐流某一行右侧空着、下方仍有卡片的问题：用后面的普通卡补齐空位，保留大卡的全宽尺寸，允许局部调整展示顺序。对应 [#19](https://github.com/Fab1e2000/NeoBili/issues/19)。
- 修复评论排序、刷新、分页和删除并发时，迟到的请求结果覆盖当前内容或恢复已删除评论的问题。

本次构建号为 19。

## 安装

最低系统要求 iOS 26。安装包没有 Apple 开发者证书，只带 ad-hoc 签名；可通过 SideStore、AltStore 或 Sideloadly 使用自己的 Apple ID 重签安装。

下载本页附件 `NeoBili-v1.4.0-unsigned.ipa`，并用同页的 `SHA256SUMS.txt` 校验文件。

SideStore 软件源（在「源」页添加）：

- [国内源](https://n015.top/neobili/apps.json)
- [备用源](https://cdn.jsdelivr.net/gh/Fab1e2000/NeoBili@main/sidestore/apps.json)

两个源的内容相同，公开发布后自动同步本次版本。软件源地址不是 IPA，不能填入 SideStore 的 App 页链接入口。

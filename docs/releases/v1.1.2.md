# NeoBili v1.1.2 — 手动播放与首页体验改进

NeoBili v1.1.2（构建 10）新增视频详情自动播放开关，并改进首页、视频页布局和图片加载。

## 新功能与改进

- 新增视频详情自动播放开关，默认开启。关闭后可先浏览简介和评论，点击播放按钮再开始播放。
- 手动播放模式支持先选择分集；进入其他视频时重新读取播放设置。缩略播放器也支持开始播放等待中的视频。
- 重做首页推荐信息流，并优化图片加载和播放进度跟踪。
- 修复视频页顶部安全区域及播放器与页面内容之间的间隙。
- 补充手动播放、页面切换和缩略播放器回归测试，改进测试隔离与开发文档。
- 将独立产品网站和旧图标方案移出 App 源码仓库，保留当前图标源文件和必要开发资源。

感谢 @yamakze（Zeno.Chen）贡献视频详情自动播放开关。

## 下载与安装

- `NeoBili-v1.1.2-unsigned.ipa`：Release 配置构建，未签名；安装前需要使用自己的证书或签名工具签名。
- `SHA256SUMS.txt`：下载校验文件，在同一目录运行 `shasum -a 256 -c SHA256SUMS.txt` 校验。

**系统要求**：iOS 26.0 或更高版本的 iPhone。

NeoBili 是独立的第三方项目，与哔哩哔哩无官方关联。

# NeoBili v1.3.6 — 视频章节、播放模式与浏览体验改进

## 播放与离线缓存

- 支持查看带章节视频的当前章节、从菜单直接跳转，以及在拖动进度或横滑画面时预览目标章节。新缓存的视频会保存可用章节，断网时也能跳转。已有缓存仍可播放，重新缓存即可获取可用章节。
- 播放器新增洗脑循环和自动切集或连播开关，关闭后可在播完时暂停。有可用音轨时，可在播放器中选择 Hi-Res 无损音质。

## 浏览与性能

- UP 主空间新增「合集和系列」入口，直播页顶部保留正在开播的关注主播头像。
- 收藏夹改用简洁的原生列表，支持长按管理。搜索使用原生搜索框，并重新组织热搜、历史记录与搜索建议的展示。
- 优化评论首批加载、快速滚动与分页追加时的列表更新，同时改善弹幕、投屏、图片缓存和播放器调度。

## 应用更新

- 「设置 → 关于 → 应用更新」支持自动与手动检查更新。发现新版本时以红点提示，可从详情打开 SideStore 或 AltStore，也可下载 IPA 并分享给签名工具。

本次构建号为 23。

## 安装

支持 iOS 26 及以上版本。下载附件 `NeoBili-v1.3.6-unsigned.ipa`，可用同页的 `SHA256SUMS.txt` 校验。通过 SideStore、AltStore 或 Sideloadly 使用自己的 Apple ID 重签安装。

SideStore 可添加[国内源](https://n015.top/neobili/apps.json)或[备用源](https://cdn.jsdelivr.net/gh/Fab1e2000/NeoBili@main/sidestore/apps.json)。

## 表 ③ 当前实现与证据边界

本表按当前源码维护；“已接入”表示客户端实现存在，不表示服务端已验收或推荐效果一致。官方字段证据和地址保留在各契约条目中。

| 范围 | 当前实现 | 仍须区分的边界 |
| --- | --- | --- |
| 设备、访客、票据 | AppDeviceRegistration、AppGuestRegistration、AppTicket 已接入自身资料、结果持久化及公共请求头 | 设备管理可见、fingerprint 接受、推荐关联是不同检查 |
| 推荐解析与曝光 | 保留原始批次位置、追踪字段，采集可见卡片和每段时长 | 过滤后的 UI 顺序不等于原始服务端位置；不能据上报成功推断兴趣更新 |
| 刷新与分页 | 分离被采纳批次首 idx 与原始页尾 idx；分页不覆盖刷新头，暂存刷新在采纳后更新 | 来源为8.89 HD2；9.13相同边界未独立动态验收 |
| 观看时间 | 墙钟观看与倍率加权时长分开；起播 data.ts 按播放 session 消费 | 暂停、缓冲、seek 不能增加有效观看；倍率语义来自8.89，9.13受控倍速未验收 |
| 日志封包 | Neuron-Events 使用实际编码帧数；已有批量、持久队列及前后台门禁 | 不照搬旧包全部重试/定时器；服务器消费未验证 |
| 横幅状态 | 账号隔离；后台跨度严格大于1800秒时清理摘要 | 8.89静态规则，9.13样本仅相容；Banner新模型采纳时点未全复刻 |
| 登录续期 | info→timestamp→refresh→持久化→旧凭据confirm 已接入 | 明确失效需允许重新授权；不因普通网络故障登出或清除Cookie |
| 播放器与资料库 | 已有播放器操作日志、倍速、稍后再看v2分页 | 其余独立应用心跳/新业务不因协议存在就加入高频任务 |
| 固定配置 | 中国locale、关闭自动刷新、静音等依既定产品策略；网络按真实状态 | 不把固定策略、能力声明和官方版本差异混成同一缺陷 |
| 其它未逐项复核内容 | 结束报告跨进程恢复、首页磁盘兜底、全部gRPC及业务配置覆盖 | 不由此次有限审计宣称全部完成；逐项按实际业务需求及证据评估 |

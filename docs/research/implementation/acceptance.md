# 维护与验收

[研究导航](../README.md) · [本主题目录](../../RECOMMENDATION_IMPLEMENTATION_REVIEW.md)

身份、登记、ticket、点击/曝光、观看和负反馈已有实现；维护时按以下顺序检查受影响链路。

1. 先核对当前入口、所属状态与请求通道，记录适用版本和字段来源，使用脱敏的确定性样本。
2. 身份和写请求重点验证账号代际、持久化结果、迟到回执及失败策略；登记、票据、续期分别处理。
3. 行为事件覆盖真实操作、可见区和播放进度，保留服务端原始卡片字段，测试预载与取消边界。
4. 按[开发与测试指南](../../DEVELOPMENT.md)运行相关检查及完整验证；结果写入忽略的构建目录。
5. 需要联网或设备专项时明确操作范围。推荐效果实验固定账号、设备、入口、网络、设置和请求
   状态，观察多轮候选与内容分类，保留原始条件。

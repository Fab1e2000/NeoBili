# 使用手册

## 浏览与导航

推荐页提供视频卡片；搜索位于底部标签栏。重复点击推荐标签可回到顶部，在顶部再次点击
会刷新。设置中的标签栏可调整顺序、可见页面和启动页；标题栏提供「随内容滚动」、
「固定·切边」两个选项，适用于推荐、搜索和资料库页面。随内容滚动时不添加顶部渐变模糊。
关注和直播的标题及切换器始终固定，使用切边背景，不受标题栏设置影响。
UP 主空间的关注状态加载失败时可重试；状态尚未明确时不执行关注操作，自己的空间不
显示关注按钮。投稿和动态支持下拉刷新与失败重试，投稿刷新失败保留已显示内容。
收藏、历史与稍后再看可从个人入口访问，也可配置为标签页。
稍后再看按页加载，底部点击「加载更多」继续。历史记录、收藏夹内视频和稍后再看均支持长按多选。长按视频并点「多选」可进入选择模式，再勾选其他已加载的视频。选择后底部显示选中数量和大号操作按钮，点「完成」退出，或点击
「移出所选」移除，提交前仍有撤销机会；部分删除失败时，只恢复未成功移出的条目。下拉刷新重新加载首批。

首页自动刷新已关闭：恢复前台、返回推荐页或关闭内容页不会换掉当前列表。下拉或在顶部再次点击推荐标签仍可手动刷新，滚动到底部仍会加载更多。登录状态或推荐来源变化时会重新取推荐。
登录只提供短信验证码：选择国家或地区、填写手机号、获取验证码并登录。重发倒计时为 60 秒，验证码按五分钟有效期处理，实际有效性仍以服务器为准。需要安全验证时按页面提示完成。不会自动重发短信、回退到扫码或密码登录。
使用新版短信登录或同账号补授权后，应用会在启动和恢复前台时按需检查登录有效性，并在服务器要求时自动续期。没有后台定时轮询；暂时断网保留登录，稍后重试。旧版本未保存续期凭据，需要重新短信登录或补授权一次才能启用；升级本身不会强制退出账号。
App 接口使用 iPhone 协议身份；已有登录凭据保留。旧 Android/HD 或 Cookie-only 会话需要在「设置 → 推荐流 → 验证码授权」用当前账号的手机号补授权，不必先退出登录，也不会用另一账号的结果覆盖当前登录。客户端身份统一不保证推荐质量提升。

“设置 → 浏览 → 推荐流 → 推荐来源”可选移动端、网页或混合推荐，保存后完全退出并重新打开生效。混合模式交错显示两路结果并去重；移动端继续使用当前 iOS 登录身份。网页模式可直接使用网页登录状态，混合模式与移动端模式需要已有的 App 授权。

关注页顶部头像条用于切换全部动态与 UP 主动态，展示直播和未读状态；全部关注入口打开
完整列表。轻点有更新的 UP 主会同步已读状态。再次轻点当前已显示个人动态的头像进入 UP 主主页；长按头像直接进入直播间，未开播时提示当前未开播。

动态和评论的配图可点开查看，从点击的图片开始。默认加载预览图，点右下角的轻量「查看原图」按钮再下载高清原图；下载原图时保留已显示的预览图。
每张图均可左右切换，尚未加载时显示进度，失败时可重试，不会阻挡其他图片。支持双指或双击缩放、动图展示和分享当前已加载图片。

## 视频与直播

点击视频卡片打开详情，简介、评论、合集和分 P 提供对应内容入口。播放器轻点显隐控件，
可选择服务端提供的画质与音质；需要登录或大会员的档位受账号权限限制。请求被拒绝或降档
时会提示，不能保证所有视频都提供所有档位。
视频详情加载失败时可在当前页点击「重试」，无需先关闭小窗或换片。切换分 P 后再打开
相关视频、合集或评论视频链接，返回会恢复离开前的分 P。

启动和只浏览页面不会申请有声播放的音频焦点，首页静音预览也不申请；有声播放才激活
音频会话，暂停、结束或关闭播放后通知外部音频应用可恢复。

前台播放视频或直播时，屏幕保持常亮，小窗继续播放也适用。暂停、播放结束、关闭播放或
切到后台后恢复系统自动变暗与锁屏；手动锁屏仍由系统处理。

「设置 → 播放与画质 → 详情页直接播放」默认开启。关闭后，打开详情页先显示封面并
加载页面内容，点击中央播放键才开始播放；也可从缩略播放器启动。播放前选择分 P 不会
自动开播，播放后切换分 P 会继续播放。列表的播放地址预取开关独立生效。

播放器更多菜单里的「播放倍速」可选 0.5×、0.75×、1×、1.25×、1.5×、2×。
同一视频暂停、继续或切换画质时保留倍率，新视频默认 1×；首页预览与直播不受影响。
观看上报仍按真实经过的时间累计，例如 2× 播放 10 秒只记 10 秒观看，播放位置约前进 20 秒。

轻点画面显示或隐藏控件，双击暂停或继续播放。播放中按住画面 0.3 秒临时以 2× 播放，松手或手势中断后恢复原倍率。
横向拖动调整播放进度；竖向手势区域控制亮度、全屏与音量，可在设置中调整分区和方向。
手机音量键使用系统音量提示；音量手势期间隐藏系统提示，在播放器内显示玻璃百分比提示，
松手、取消或离开播放器后恢复系统提示。
简介或评论滚动可收缩播放区，加载/播放与暂停采用不同收缩状态；竖屏从展开尺寸缩至紧凑尺寸的过程中，仍可正常操作播放器控件。只有暂停后从紧凑尺寸继续向控制栏收缩时，点击播放器区域才会展开并继续播放。
退出详情后由底部缩略播放器继续播放。更多菜单提供稍后再看、定时休眠等操作。
定时休眠在播放地址重试期间到期也会保持暂停，地址返回后不会自行开播。

点赞、投币、收藏等轻点操作；按住点赞 0.5 秒一键三连，按住收藏 0.5 秒选择收藏夹。
需要登录的操作会提示登录。续播位置保存在本地，拖动但未实际播放的位置不会作为观看进度上报。
取得 App 登录凭据后，实际观看会发送移动心跳并同步历史；只有网页授权时仍使用网页历史同步。
推荐刷新保留服务端给 NeoBili 的游标，但不同客户端的推荐结果仍可能不同。

评论主列表和回复详情在时间后显示接口提供的 IP 属地（如「2025.04.26 · 湖北」），缺失时不显示；
楼中楼预览不显示属地，进入回复详情后可见。
视频评论中的 `02:35`、`1:02:03` 等时间可点击跳到当前分 P 的对应进度；播放器未就绪或
时间超过视频长度时会提示。动态评论不会控制后台视频。长正文通过「展开／收起」按钮切换，
楼中楼可点击回复用户名或「查看全部 N 条回复」进入详情。

评论链接优先显示服务端标题。普通 BV/av 视频链接在 App 内打开并保留视频返回路径，
`b23.tv` 短链尝试解析后打开；其他网页、带分 P／时间参数的视频链接在内置浏览器打开，
保留完整 URL。短链解析失败也回退到浏览器。

直播标签提供推荐与关注列表。直播间支持清晰度选择、重新连接、弹幕及主播资料，
没有点播进度轴或续播位置。退出直播详情后可由缩略播放器继续播放。
视频和直播弹幕支持保留原色或统一白色；视频弹幕在首帧后加载，直播弹幕可延后连接。

## 设置

「我的」左上角齿轮始终提供系统设置入口，访客、账号恢复中或资料加载失败时也可使用。

| 分组 | 选项 |
| --- | --- |
| 外观 | 主题色、文字大小、语言、动画 |
| 浏览 | 标签栏、标题栏、内容过滤、推荐流、滚动与防误触 |
| 播放 | 播放与画质、弹幕、播放器手势、控件位置 |
| 高级 | 设备编号；Debug 构建另有推荐实验日志 |
| 账号 | 账号管理 |
| 关于 | 应用信息 |

语言支持跟随系统、简体中文与 English，切换后重新打开生效；服务端内容保持原文。
应用字号共 7 档，默认第 4 档。主题色同步影响应用外观及替代图标。

内容过滤可隐藏竖屏视频，或设置最低视频时长（0–1440 分钟，0 为不限）。缺少元数据时
先补查再展示；关闭动画不跳过过滤。直接打开的视频不受列表过滤影响。

动画总开关只控制自定义效果，保留系统导航与菜单。推荐、直播卡片可控制进入和退出，
搜索卡片可控制进入；空间、相关视频、收藏、历史、稍后再看与合集不提供自定义卡片动画。
动态退出、关注刷新后的整列进入和页面淡入分别控制。关闭动画时，相应等待立即结束。

下拉刷新距离默认 40 pt，可调 40–140 pt。左缘防误触默认 30 pt，可调 0–100 pt，
0 为关闭；该区域会拦截点击，也影响从区域内部开始的竖向滚动，系统边缘返回保留。

退出登录需确认，之后回到访客模式。暂时的网络问题不代表账号凭据已失效。
短信验证成功但保存失败时可「重试完成登录」，不重新发送短信；手机号与当前补授权账号
不匹配时可重新验证。登录会话已变化则关闭表单后重新开始。

推荐内容过滤中的「本地屏蔽名单」可按 UID 解除本机的推荐过滤，下一次刷新推荐生效。
它与哔哩哔哩账号黑名单独立：按首页提示在官方 App 或网页解除拉黑后，也需解除本地屏蔽。
开发和测试环境的使用方式见 [开发与测试](DEVELOPMENT.md)。

## 本地推荐实验（Debug）

设置 → 推荐流 → 推荐实验日志可以开关手机日志，准备导出后分享文件。日志仅记录首页推荐和观看上报的白名单字段，不保存登录凭据、原始设备编号或完整网络正文；最多保留约 8 MB，超过后滚动覆盖。导出包含视频标题与操作时间，请按个人浏览记录保管。

本地测试可使用已授权的官方设备编号；它保存在本机独立的实验设置中，不覆盖 NeoBili 自身编号，不进入源码。页面可恢复自身编号。Release 不使用实验编号或记录诊断日志。

UP 主个人主页优先显示 App 空间接口提供的头图，深色外观使用可用的夜间头图。接口失败或没有有效头图时回退到名片背景，再回退到主题渐变；不播放背景装扮动画。

在「设置 → 推荐流」中，「刷新后保留上次数据」默认开启：新卡片排在前面，旧卡片保留在后面；关闭后从下一次刷新起整批替换。搜索框聚焦时隐藏历史、热搜和已有结果，输入非空文字后显示搜索建议；取消后恢复历史/热搜或已有结果。

### 设备编号

首次进入页面时会提示编号可能影响推荐，点击「知道了」后不再显示。若想尝试让推荐更接近官方 App，可抓取自己官方 App 的请求，查看请求头中的 `buvid`，将其复制到设备编号输入框并保存，再完全退出并重新打开 NeoBili。只使用自己的编号，不分享完整抓包或使用他人的编号；同一编号不能保证推荐完全一致。

设置 → 高级 → 设备编号可填写并保存自己的 BUVID，保存后从后台退出 App 再打开生效。留空则使用固定保存的随机编号，不每次刷新更换。页面显示当前实际使用的编号，支持选择复制。修改编号会使用对应设备的登记和票据缓存，账号登录保持不变；不保证改变推荐质量。

## 设置导航

设置按外观、浏览、播放、账号、高级和关于分类。动画在“外观”，播放器手势和控件位置在“播放”。“浏览 → 内容过滤”集中提供全局与推荐过滤；推荐来源和授权仍在“浏览 → 推荐流”。调整分类不会重置已有选择。

播放数据允许没有独立音轨，静音视频仍可加载；这与竖屏过滤设置无关。

### 设置选项说明

设置页保留选项与必要的状态提示，详细行为在此查阅：

- 字号独立于系统字号；跟随系统语言时，中文系统显示中文，其他语言显示英文。
- 关闭缩略播放器后，退出视频页停止播放，底部标签栏保持展开；开启时可继续播放，标签栏可随滚动收缩。
- 预取播放地址只请求地址，不下载媒体，会增加接口请求；对推荐结果的影响尚未确认。
- 内容过滤作用于推荐、关注、搜索、收藏、历史等列表。点赞率、播放量、关键词与关注豁免只影响推荐，全局画幅和时长规则仍然生效。
- 下拉刷新距离由推荐、直播和关注页共用，距离越短越容易触发。调整左缘防误触滑杆时会高亮对应范围。
- 屏蔽顶部或底部弹幕只影响固定弹幕；弹幕显示设置同时用于视频和直播。
- 控件位置预览按本机尺寸缩小，圆角和灵动岛仅为近似示意。竖屏视频全屏时使用非全屏那组位置。
- 控件边距按可见控件计算，0 表示贴边；横屏左右边距默认跟随系统安全区，手动调得过小可能进入屏幕圆角区域。

合集与分 P 列表打开时定位当前播放项；在列表内切换只更新选中项，保留浏览位置。

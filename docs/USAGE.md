# 使用手册

## 浏览与导航

推荐页提供视频卡片；搜索位于底部标签栏。重复点击推荐标签可回到顶部，在顶部再次点击
会刷新。设置中的标签栏可调整顺序、可见页面和启动页；标题栏提供「随内容滚动」、
「固定·切边」「固定·渐变」三个选项，适用于推荐、搜索和资料库页面。
关注和直播的标题及切换器始终固定，使用切边背景，不受标题栏设置影响。
收藏、历史与稍后再看可从个人入口访问，也可配置为标签页。

首页自动刷新已关闭：恢复前台、返回推荐页或关闭内容页不会换掉当前列表。下拉或在顶部再次点击推荐标签仍可手动刷新，滚动到底部仍会加载更多。登录状态或推荐来源变化时会重新取推荐。
登录只提供短信验证码：选择国家或地区、填写手机号、获取验证码并登录。重发倒计时为 60 秒，验证码按五分钟有效期处理，实际有效性仍以服务器为准。需要安全验证时按页面提示完成。不会自动重发短信、回退到扫码或密码登录。
App 接口使用 iPhone 协议身份；已有登录凭据保留。旧 Android/HD 或 Cookie-only 会话需要在「设置 → 推荐流 → 验证码授权」用当前账号的手机号补授权，不必先退出登录，也不会用另一账号的结果覆盖当前登录。客户端身份统一不保证推荐质量提升。

关注页顶部头像条用于切换全部动态与 UP 主动态，展示直播和未读状态；全部关注入口打开
完整列表。轻点有更新的 UP 主会同步已读状态。长按头像可查看空间，直播中的 UP 主可进入直播间。

## 视频与直播

点击视频卡片打开详情，简介、评论、合集和分 P 提供对应内容入口。播放器轻点显隐控件，
可选择服务端提供的画质与音质；需要登录或大会员的档位受账号权限限制。请求被拒绝或降档
时会提示，不能保证所有视频都提供所有档位。

「设置 → 播放与画质 → 详情页直接播放」默认开启。关闭后，打开详情页先显示封面并
加载页面内容，点击中央播放键才开始播放；也可从缩略播放器启动。播放前选择分 P 不会
自动开播，播放后切换分 P 会继续播放。列表的播放地址预取开关独立生效。

横向拖动调整播放进度；竖向手势区域控制亮度、全屏与音量，可在设置中调整分区和方向。
简介或评论滚动可收缩播放区，加载/播放与暂停采用不同收缩状态；点击暂停收缩栏可展开继续播放。
退出详情后由底部缩略播放器继续播放。更多菜单提供稍后再看、定时休眠等操作。

点赞、投币、收藏等轻点操作；按住点赞 0.5 秒一键三连，按住收藏 0.5 秒选择收藏夹。
需要登录的操作会提示登录。续播位置保存在本地，拖动但未实际播放的位置不会作为观看进度上报。
取得 App 登录凭据后，实际观看会发送移动心跳并同步历史；只有网页授权时仍使用网页历史同步。
推荐刷新保留服务端给 NeoBili 的游标，但不同客户端的推荐结果仍可能不同。

直播标签提供推荐与关注列表。直播间支持清晰度选择、重新连接、弹幕及主播资料，
没有点播进度轴或续播位置。退出直播详情后可由缩略播放器继续播放。
视频和直播弹幕支持保留原色或统一白色；视频弹幕在首帧后加载，直播弹幕可延后连接。

## 设置

| 分组 | 选项 |
| --- | --- |
| 外观 | 主题色、文字大小、语言 |
| 浏览 | 标签栏、标题栏、内容过滤、推荐流 |
| 播放 | 播放与画质、弹幕 |
| 高级 | 动画、播放器手势、控件位置、滚动与防误触 |
| 账号 | 账号管理、关于 |

语言支持跟随系统、简体中文与 English，切换后重新打开生效；服务端内容保持原文。
应用字号共 7 档，默认第 4 档。主题色同步影响应用外观及替代图标。

内容过滤可隐藏竖屏视频，或设置最低视频时长（0–1440 分钟，0 为不限）。缺少元数据时
先补查再展示；关闭动画不跳过过滤。直接打开的视频不受列表过滤影响。

动画总开关只控制自定义效果，保留系统导航与菜单。推荐、直播卡片可控制进入和退出，
搜索卡片可控制进入；空间、相关视频、收藏、历史、稍后再看与合集不提供自定义卡片动画。
动态退出、关注刷新后的整列进入和页面淡入分别控制。关闭动画时，相应等待立即结束。

下拉刷新距离默认 40 pt，可调 40–140 pt。左缘防误触默认 30 pt，可调 0–100 pt，
0 为关闭；该区域会拦截点击，也影响从区域内部开始的竖向滚动，系统边缘返回保留。

退出登录需确认，之后回到访客模式。暂时的网络问题不代表账号凭据已失效。
开发和测试环境的使用方式见 [开发与测试](DEVELOPMENT.md)。

## 本地推荐实验（Debug）

设置 → 推荐流 → 推荐实验日志可以开关手机日志，准备导出后分享文件。日志仅记录首页推荐和观看上报的白名单字段，不保存登录凭据、原始设备编号或完整网络正文；最多保留约 8 MB，超过后滚动覆盖。导出包含视频标题与操作时间，请按个人浏览记录保管。

本地测试可使用已授权的官方设备编号；它保存在本机独立的实验设置中，不覆盖 NeoBili 自身编号，不进入源码。页面可恢复自身编号。Release 不使用实验编号或记录诊断日志。

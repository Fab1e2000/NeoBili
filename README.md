# NeoBili

使用 SwiftUI 和 Swift 6 开发的第三方哔哩哔哩 iOS 客户端，支持 iOS 26 及以上版本，播放内核使用 MPVKit。

## 功能

- 推荐视频、搜索、关注动态与 UP 主空间
- 独立直播页：推荐、登录后的关注直播，支持横向滑动切换、直播画质切换、重新连接和分享
- 视频播放、播放控制与清晰度选择；按视频和分 P 记忆本机播放进度
- 未开启隐藏竖屏时，非全屏播放区按实际画幅调整高度，长竖屏保留详情区域
- 竖屏视频保持竖向全屏；播放中上滑评论或推荐列表可缩到标准视频高度，也可用画面控件收缩、展开
- 视频与直播退出详情后继续播放，底部缩略播放器显示标题，支持展开、播放/暂停和关闭
- 播放器使用原生 SwiftUI 深色玻璃控件，底部缩略播放器随 TabView 收缩；搜索集成在底部导航中
- 视频、直播与动态卡片的进入/退出动画可分别关闭；关注页标题下方的横向头像条可一键切换 UP 主动态
- 评论、收藏、稍后再看与历史记录
- 账号登录与个性化设置

## 设置与使用

入口：**我的 → 系统设置**。设置页仅保留分类、控件与当前数值，详细行为在这里说明。

### 播放

#### 播放与画质

- **分辨率、音质**：作为之后新打开视频的首选档位。可用档位由视频与账号权限决定；不可用时使用可用档位。不会为应用默认设置强制重开当前视频。
- **持续播放**：退出视频或直播详情后，播放会继续，页面缩回底部缩略播放器。缩略播放器仅显示标题与操作按钮；点击标题重新展开，播放/暂停按钮控制当前媒体，关闭按钮或长按菜单结束播放。紧凑布局隐藏关闭按钮，可通过长按菜单关闭。

#### 播放控件

轻点画面显示原生 SwiftUI 玻璃控件。返回位于左上角，更多菜单位于右上角，播放/暂停始终位于画面中央，全屏按钮独立放在右下角。主要按钮和菜单使用至少 48 × 48 pt 的矩形点击区域，圆形玻璃外观的四角也可点击；进度条的操作高度为 48 pt。

- **全屏底栏**：当前时间、进度条、总时长与退出全屏按钮排列在同一行，不再显示分享按钮。横屏全屏时，上下控件行可使用视频两侧的黑边，同时保留屏幕圆角、Home 指示条和灵动岛所需的避让空间。
- **顶部画质菜单**：分辨率和音质各有独立的文字菜单，直接显示当前采用的档位，胶囊宽度随文字长度变化，点击区域仍至少为 48 × 48 pt。菜单同时识别服务端声明的 2K、4K 等档位；若首批播放数据尚未包含所选档位的地址，会按所选分辨率重新请求，成功取得该档位才切换。需要登录或大会员的选项会标注要求；服务器降档或拒绝时保留原播放源并提示。顶部空间允许时补充显示视频标题。
- **更多菜单**：省略号菜单提供“稍后再看”和“定时休眠”；“稍后再看”需要登录。可收缩的非全屏画面也可从这里收起或展开。
- **非全屏画幅**：16:9、21:9 等常规画幅在底部显示时间、进度条与独立全屏按钮；较高的竖屏、方形画幅可在进度条下方保留“收起/展开”文字胶囊。更矮的画幅先隐藏时间文字、缩短进度条；极矮画幅将操作收为单排，并将画质、音质选项放入更多菜单。
- **进度与自动隐藏**：打开视频时控件默认隐藏，加载和缓冲期间也可轻点画面显示或隐藏；控件隐藏时仅保留加载指示。进度滑块仅在拖动时出现，松手后跳转。播放时控件在 3 秒后隐藏；按下菜单按钮时暂停这次自动隐藏，VoiceOver 开启时保持显示。
#### 播放器手势

- 预览图显示亮度、全屏、音量三个竖向滑动区域。默认分界为播放器宽度的 33% 和 67%；分界滑杆用于调整各区宽度。
- **全屏比例预览**只改变设置页示意图，便于查看宽屏区域分布。
- **反转上下滑**改变竖向手势方向。默认左侧上滑增加亮度、右侧上滑增加音量；中间区域切换全屏。横向滑动用于调整播放进度，松手后跳转。
- **恢复默认分区**恢复两条分界与上下滑动方向。


#### 视频画幅与收缩

关闭“隐藏竖屏视频”后，非全屏播放区按视频实际画幅调整；竖屏全屏保持竖向。简介、评论列表的上滑可以缩小视频区域，缩小不会暂停正在播放的视频。

| 视频状态 | 横屏视频 | 竖屏视频 |
| --- | --- | --- |
| 尚未显示首帧或重新加载 | 保持实际画幅 | 最多缩到标准 16:9 视频高度 |
| 正在播放 | 保持实际画幅 | 最多缩到标准 16:9 视频高度 |
| 已完成加载并暂停 | 可继续收到 56 pt 粉色栏 | 可继续收到 56 pt 粉色栏 |

加载状态不会套用暂停收缩。暂停后继续上滑时，画面尺寸与粉色覆盖由同一滚动进度连续变化；状态栏、画面和下缘间隔共用一层颜色，不分段跳变。迟到的画幅元数据会保留合理的收缩位置；继续播放时恢复完整可见画面。播放器尚未完全展开时，内容区的竖向滑动优先用于滚动和展开，不触发缩放返回；横向返回仍保留。简介或评论列表回到顶部后，继续下拉可从收缩中途或粉色栏逐步展开播放器；这种手势保持原来的播放/暂停状态。点击粉色栏则展开并继续播放。离开视频页或进入 UP 主空间等其他页面后，原视频页不再消费滚动手势。

简介顶部使用独立的 UP 主玻璃胶囊与标题简介玻璃卡片。轻点头像或名称打开个人空间，右侧按钮关注；标题始终完整显示，玻璃卡片随标题行数调整高度，单行标题与播放信息保持紧凑间距；轻点整张简介玻璃卡片（标题、统计信息、箭头或留白）即可展开或收起正文；箭头表示当前状态，展开后仍可长按选择正文。标签与互动操作位于卡片下方。评论的点赞与回复使用普通按钮，保留 44 pt 点击区域，评论正文、操作与回复预览之间的间距更紧凑。楼中楼预览使用可点击的圆角玻璃容器，轻点整块进入全部回复；全部回复页沿用相同的玻璃样式。

### 直播

底部 **直播** 标签提供“推荐”和登录后的“关注”两个列表，双列房间卡片展示封面、人气、主播与标题，卡片使用独立背景。直播标签位于推荐左侧，默认打开推荐页；顶部推荐/关注选择器可点击或横向滑动切换，并随“标题栏”设置与标题一起固定或随内容滚走。支持下拉刷新、分页加载和失败重试，下拉时不显示刷新提示浮层。直播卡片沿用视频卡片的进入与刷新退出动画；可在“动画 → 直播 → 直播卡片”中分别关闭。

- **播放与清晰度**：直播间顶部的独立文字菜单显示当前清晰度，点击可选择服务端提供的档位，切换后重新连接；极矮画幅将清晰度选项收进更多菜单。省略号菜单提供“重新连接”和分享。
- **主播与简介**：头像、名称、粉丝/视频数和关注按钮位于与视频详情一致的玻璃胶囊中。下方玻璃卡片始终显示完整标题与直播信息，轻点整张卡片展开或收起简介和公告，箭头表示当前状态；关注操作沿用当前账号，未登录时会提示登录。
- **连接速度**：播放地址与主播资料同时加载，播放不等待资料；首个地址复用已预热的内核。优先直连 FLV，并保留 HLS 备用线路；每个地址的首帧等待上限为 10 秒，最多使用 4 个服务端提供的地址。
- **直播状态**：控件显示“直播中”或“连接中”，不提供点播时间轴、进度跳转或续播位置记忆。尚未开播或连接中断时显示对应状态和重新连接入口。
- **画幅与退出**：播放区随实际画幅调整，竖屏直播全屏时保持竖向。直播间与视频详情使用相同的缩放卡片转场和退出手势，退出后由底部缩略播放器继续播放。

### 内容

#### 内容过滤

- **隐藏竖屏视频**：在视频列表中隐藏竖屏稿件。缺少尺寸时先补查并缓存，避免先显示再移除。
- **最短视频时长**：0 表示不限制；其他数值隐藏短于该分钟数的视频，恰好达到阈值的会保留。可设置 0–1440 分钟。
- 缺失信息的判断和必要的补页完成后，列表显示通过过滤的内容。此等待属于内容过滤，不属于卡片动画；关闭动画不会绕过过滤。
- 直接链接和已经打开的视频不受列表过滤影响。

#### 关注页

- 标题下方是横向头像条：「全部动态」在最前，随后是正在直播和最近有动态的 UP 主（有未读的排在前面），末尾「全部关注」进入完整关注列表（每行五个头像，轻点进入 UP 主主页）。
- 轻点头像立即切换下方动态，旧动态淡出、新动态淡入；可在“动画 → 动态”中关闭。
- 标题栏设为“固定在顶部”时，头像条与标题一起常驻顶部；设为“随内容滚动”时，二者一起滚出页面。
- 正在直播的 UP 主头像下方显示 **LIVE**，排在有动态更新的 UP 主之前；没有近期动态的关注主播也会出现在头像条中。每组保持原顺序。
- 红点与 B 站同步：以 B 站返回的更新标记为准，点选有红点的 UP 主时立即清除，并按网页动态页的方式加载他的动态，让 B 站同步清除；这位 UP 主在原位保留五分钟后再回到默认顺序。在「全部动态」里浏览不会清除红点。
- 长按头像可查看 UP 主主页；正在直播时额外提供“进入直播间”。
- 开播信息在关注页可见时独立刷新，不阻塞动态加载；下拉刷新也会同步更新。暂时请求失败会保留已知直播状态，成功完整加载后再移除下播标记。

### 界面与交互

#### 语言

“外观 → 语言”可选跟随系统、简体中文或 English，默认跟随系统：系统语言为中文时显示中文，其它语言显示英文。切换后需完全退出并重新打开应用。英文界面沿用 B 站说法（UP、Danmaku、Coin 等），大数字显示为 K/M/B；B 站返回的标题、评论、热搜、服务端错误信息等内容保持原文。

#### 文字大小

应用提供 7 档文字大小，默认第 4 档。预览文字随调整实时变化，应用内的页面和模态窗口使用同一档位。此设置覆盖系统动态字体档位，避免重复缩放。

#### 动画

**自定义动画**为总开关，默认开启。关闭后停用应用额外制作的卡片动画和页面淡入，卡片立即到达最终显示状态；导航、菜单、原生 Picker 等系统动画保留。关闭总开关不会清除下面的各项选择。系统「减弱动效」同样会停用自定义卡片效果。

视频卡片按所在页面单独控制。每个来源只显示当前实际存在的自定义动画阶段：

| 来源 | 可设置的阶段 | 影响范围 |
| --- | --- | --- |
| 推荐页 | 进入、退出 | 首次展示、刷新落位、换一条的入场，以及下拉刷新时旧卡片淡出 |
| 搜索页 | 进入 | 首页搜索及其他搜索入口的结果卡片 |
| UP 主空间 | 进入 | UP 主空间的视频列表 |
| 收藏 | 退出 | 从收藏夹移除视频时的淡出与空位收拢 |
| 历史记录 | 退出 | 删除观看历史时的淡出与空位收拢 |
| 稍后再看 | 退出 | 移出稍后再看时的淡出与空位收拢 |

视频详情页的相关视频直接排列在页面背景上，不使用整体玻璃容器，也不播放卡片进入动画。

收藏、历史、稍后再看保持原有直接入场方式，不额外增加入场特效。合集与分 P 列表使用与搜索结果一致的独立视频卡片，没有额外的整体容器或自定义卡片动画。

**动态卡片**统一设置进入和退出，不再区分关注流、UP 主空间等来源；视频动态内部的视频仍随动态设置。**页面淡入**单独控制主页面切换时额外添加的淡入效果。

**直播卡片**单独控制进入和退出，默认开启，复用视频卡片的落位与淡出效果。翻页追加的新卡片可以进入，已经显示过的卡片在滚回屏幕时不会重复播放动画。

**进入速度、退出速度**沿用原有速度设置，范围 0.1–10.0 倍，默认 1.0 倍，倍率越大越快。进入速度作用于卡片落位与页面淡入；退出速度作用于推荐/关注/直播刷新淡出。收藏等移除的淡出与空位收拢保持各自既有时长。

关闭某项动画时，正在等待该项动画结束的刷新或移除流程立即继续。其他页面独立的动画等待不受影响。已经跳过的入场动画在重新开启开关或懒加载卡片重新出现时不会补播。

#### 滚动与防误触

- **下拉刷新距离**：推荐与关注页共用。默认 70 pt，可调 40–140 pt，每步 5 pt。达到距离后松手刷新，回推可取消。再次点击底部「推荐」可回到顶部；已经在顶部时再次点击则刷新。
- **左缘触控死区**：默认 16 pt，可调 0–100 pt；0 为关闭。该区域拦截点击以防止滑动返回时误触卡片，系统边缘返回仍可使用。由于区域拦截触摸，从其内部开始的竖向列表滚动也会受阻。拖动滑杆时会短暂显示实际覆盖范围。

### 账号与关于

- **账号管理**显示当前用户与 UID，退出登录需确认。退出后回到访客模式，需要登录的功能需重新登录使用。
- **关于**显示版本、界面修订、播放内核及参考项目。

## 构建

1. 使用支持 iOS 26 SDK 的 Xcode 打开 `NeoBili.xcodeproj`。
2. 等待 Swift Package Manager 解析 MPVKit 依赖。
3. 在 Signing & Capabilities 中选择自己的开发团队，按需修改 Bundle Identifier。
4. 选择 `NeoBili` scheme 和目标设备进行构建。

项目使用白底叠层播放图标，源文件位于 `NeoBili/Resources/AppIcons/`，由 Icon Composer 格式编译。默认粉色，修改应用主题色时会同步切换桌面图标；可编辑矢量源文件和生成脚本位于 `design/app-icon-2026/` 与 `scripts/generate-app-icons.py`。

仅编译真机目标、不签名：

```sh
xcodebuild -project NeoBili.xcodeproj -scheme NeoBili \
  -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build
```

工程生成配置保存在 `project.yml`，需要重新生成工程时可使用 XcodeGen。

## 弹幕与启动加载

在「设置 → 播放与画质 → 弹幕」中切换彩色弹幕，默认保留 B 站原色，关闭后以白色显示。该开关适用于视频和直播，不随机改色。

为优先显示首帧，视频弹幕在首帧后加载，XML 解析在后台执行。直播弹幕最多延后 800 毫秒连接；首帧提前出现时立即连接，视频加载失败也不阻止聊天连接。实际首帧速度仍受网络和直播源影响。

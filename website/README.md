# NeoBili 产品页

产品页为静态 HTML、CSS 和 JavaScript，资源使用相对路径，不需要构建。
应用的行为说明以根目录 README 和 `docs/USAGE.md` 为准；本页描述网站实现，不定义 App 布局。

## 文件与内容

| 文件 | 职责 |
| --- | --- |
| `index.html` | 中英文文案、分区、手机演示结构和下载入口 |
| `styles.css` | 页面布局、主题及响应式规则 |
| `device.css` | 3D 手机与手机内部的自绘演示界面 |
| `main.js` | 语言、主题、滚动转场、标签栏及字号演示 |
| `release.js` | 版本、构建号、下载地址和版本亮点 |
| `assets/` | 网站图标等静态资源 |

页面包含首屏、宣言、内容过滤、性能、SwiftUI、自定义和下载分区。
自绘界面是产品演示，不是当前 App 的测试截图或性能证据。更新它时对照当前实现，
不要把网站中的固定画布尺寸反向写入 App。性能文案必须有实现或测量依据。

## 本地预览

```sh
python3 -m http.server 8080 --directory website
```

打开 <http://localhost:8080/>，`?lang=en` / `?lang=zh` 指定语言。
检查两种语言、深浅色、窄屏、放大文字、减弱动效和禁用 JavaScript 时的下载入口。

## 更新与部署

发版时更新 `release.js` 中的版本和链接，核实文件大小和更新说明；同步中英文文案。
主题色、标签栏或字号档位改变时，对照 App 的设置类型更新演示数据。
图标源为 `design/app-icon-2026/BMark-white-master.svg` 与当前生产预览，更新网站图标时保持一致。

修改 CSS、JS 或图片后同步资源查询版本号，避免浏览器继续使用旧缓存。
部署目标和服务器缓存策略以当前发布任务为准，不假设其他本地仓库或服务器仍按旧配置部署。
整个目录可放到静态站点子目录；发布时验证相对资源、目录首页和下载链接。

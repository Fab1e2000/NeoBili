# NeoBili 产品页

纯静态页面，不需要构建，也不依赖外部字体、CDN 或运行时。所有资源都用相对路径引用，整个目录可以直接放进博客子目录（例如 `/neobili/`），不需要配置路由。

```
website/
├── index.html          页面结构与中英文文案（data-l="zh" / data-l="en"），以及手机里各个界面的结构
├── styles.css          页面样式；--accent 为主题色，浅色（纯白）/深色默认跟随系统，右上角按钮可手动切换并记住
├── device.css          贯穿全页的 3D 手机（iPhone 17 白色款）与手机里自绘的 NeoBili 界面
├── release.js          版本信息（发版时只改这里）
├── main.js             版本信息、语言切换，以及各段的交互演示
└── assets/
    ├── icon.svg              网站图标（取自 design/app-icon-2026/BMark-white-master.svg）
    └── apple-touch-icon.png  180×180，由 design/app-icon-2026/BMark-production.png 缩放
```

## 页面结构

页面围绕四个卖点展开：无广告、流畅、SwiftUI 原生、自定义。一部手机（`index.html` 里的 `.rig`）贯穿全页：它是 `position: fixed`，`main.js` 按滚动位置把它移到当前段落的占位框 `[data-slot]` 上。离开一个占位框就开始往下一个走（正弦缓动 + 跳跃），停在占位框里时也随滚动轻微漂浮，页面一滚手机就动。

| 段落 | 手机 | 内容与交互 |
| --- | --- | --- |
| 首屏 | 启动画面（纯白 + B），跟随鼠标视差 | 背景飘弹幕（`DANMAKU`），巨大的挤出 B 标志 |
| 宣言 | 首屏跳过来时整部手机转一圈，露出白色背面；随后停在右侧 | 粘性全屏，逐条划掉「开屏广告 / 信息流广告 / 滑动卡顿 / 数据收集」，手机上的开屏广告、广告横幅、灰色占位与卡顿、上传数据提示随之一样样消失（CSS 变量 `--p1`…`--p4`） |
| 01 无广告 | 推荐流 | 隐藏竖屏、过短视频（卡片碎掉、FLIP 补位）；「重播」让广告横幅回来再收起 |
| 02 流畅 | 推荐流自动甩动 | 停住后卡片挂上「已预取」；手机下方是还没进屏幕、已经备好的卡片。文案只讲实现上的特色，并注明汲取了 PiliPlus 等开源客户端的经验 |
| 03 SwiftUI | 随代码行切换，并高亮相关元素 | 五行真实用到的 SwiftUI 代码，注释标明出处文件：标签栏、缩放转场（关注页动态展开）、标签栏收起与缩略播放器、玻璃播放控件、横屏画质菜单（手机转成横屏） |
| 04 自定义 | 贴在左侧，标签栏可直接点 | 24 个主题色图标（手机一起换色）、标签栏编排、7 档字号（手机上的卡片标题一起变）、其余可调项清单 |
| 下载 | 启动画面 | |

减弱动效时：弹幕静止、宣言直接显示划掉后的状态、手机移动时不跳跃也不漂浮、推荐流不自动滚动。

## 手机与界面（device.css）

- **机身**：iPhone 17 白色款，71.5 × 149.6 × 7.95 mm，按 4.2 px/mm 画成 300 × 636 × 30 px。整体缩放必须用 `scale3d`（`scale()` 不缩厚度，手机一缩小就显得过厚），旋转中心在机身厚度的正中。正反两面、四条铝边拼成盒子，圆角处由 `main.js` 生成 16 圈铝框叠出厚度；左侧操作按钮与音量键，右侧电源键与相机控制；背面左上角竖向双摄。
- **界面**：`.ui` 是 402 × 874 的画布，单位直接按 iOS 的 pt 写，再缩放 0.70896 放进屏幕。位置与尺寸取自 1.1.0 的真机截图（原图含个人账号信息，只留在本地的 `design/website-screenshots/`，不入库，页面也不使用）：
  - 推荐页大标题中心 y ≈ 89，卡片从 y = 132 开始，双列，左右边距 8；卡片从大标题下面滑过，顶栏是渐隐的模糊；第二排卡片之后是横跨两列的「上次看到这里 · 点击刷新」；
  - 标签栏左右各 21、高 61、底边距 23，搜索和其他标签在同一条胶囊里；收起时变成左边当前标签的圆（x 28，直径 48）、中间缩略播放器（x 89…313，标题 + 播放）和右边单独的搜索圆（x 326）；
  - 视频页播放区 y = 53…279，玻璃控件高 34；横屏画布 874 × 402，放进竖直的屏幕后转 90°，手机本身再逆时针转 90°。
- **内容**：卡片标题、UP 主、动态都是虚构的示例，封面是浅色扁平的几何构图（`.cv.g0`…`.g5`：圆、斜切、条纹、同心拱、点阵、地平线，颜色都从卡片的 `--h` 派生）加深色大字，不使用任何真实视频或 B 站素材。横跨两列的行（广告横幅、刷新横条）只插在偶数位置；网格用 `grid-auto-flow: row dense`，隐藏竖屏或过短视频后，后面的卡片会补进空位。广告横幅收起时高度和内边距一起归零，不留空白。App 是浅色界面，不随页面切换深浅色；主题色（`--tint`）跟页面的 `--accent` 一致。

## 同步到博客（Site）

博客项目 `../Site`（React + Vite）把这个目录原样放在 `public/neobili/`，项目页 NeoBili 卡片上的「产品介绍」链接指向 `/neobili/`。这里改完后同步一次：

```sh
rsync -a --delete --exclude README.md website/ ../Site/public/neobili/
```

服务器没把 `/neobili/` 解析成目录首页时（例如 Vite 开发服务器），Site 的 `App.jsx` 会整页跳到 `/neobili/index.html`。

## 本地预览

```sh
python3 -m http.server 8080 --directory website
```

打开 <http://localhost:8080/>。加上 `?lang=en` 或 `?lang=zh` 可以指定语言；不指定时按浏览器语言显示，手动切换后会记住选择。

## 缓存

服务器给 JS、CSS 和图片设了 30 天缓存。`index.html` 里引用 `styles.css`、`device.css`、`main.js`、`release.js` 时带着 `?v=日期+字母` 的版本号；这些文件有改动时，把版本号改掉（全部替换同一个值），浏览器才会取新文件。

## 发版更新

1. **`release.js`**：更新 `version`、`build`、`size`（取 Release 页上 IPA 的体积）、`ipa`、`notes`，以及首屏胶囊里的一句话亮点 `highlightZh` / `highlightEn`。首屏、下载区和所有下载链接都从这里读取，`index.html` 里不写版本号。
2. **界面**：App 的界面有可见变化时，同步 `device.css` 与 `index.html` 里对应的自绘界面（尺寸按新截图重新量）。
3. **功能文案**：对照 `README.md` 和 `docs/releases/vX.Y.Z.md`，更新 `index.html` 里各段的中英文文案，以及 `main.js` 里的弹幕词条 `DANMAKU` 和推荐流示例 `ITEMS`。SwiftUI 段的代码行必须是 App 里真实用到的 API；流畅段只写实现上的特色，不写没有出处的数字。
4. **主题色**：`NeoBili/Core/UI/AppTheme.swift` 的颜色有增删时，同步修改 `main.js` 里的 `THEMES`。
5. **标签栏 / 字号**：`MainTabSettings.swift` 的标签或上限、`AppTextSize.swift` 的档位变化时，同步 `main.js` 里的 `TABS`、`MAX_VISIBLE`、`SCALES`。
6. **图标**：`design/app-icon-2026/` 的标志改动时，同步 `index.html` 末尾的 `#neobili-mark`、首屏 `.mega-n` 里的 `.face` 路径和 `assets/icon.svg`，重新生成 `assets/apple-touch-icon.png`；更新 HTML 中两种图标资源的 `?v=` 版本号，然后同步到博客目录。

浏览器没开 JS 时，下载按钮会指向 `releases/latest`，依赖版本信息的文字会隐藏，手机不显示，首屏换成应用图标，所以不会出现过期的版本号或空白。

## 浏览器窗口比例

桌面（宽度 ≥ 960px）按 `100svh` 排布分区，预留顶部导航与底部留白；标题、手机和装饰随可用高度缩放。自定义区采用并排卡片，文字预览直接使用标题和字号滑块。宣言保留滚动动画所需的长滚动距离，内部画面固定一屏。窄屏及放大文字时允许内容自然撑开，不裁切内容或锁住滚动。

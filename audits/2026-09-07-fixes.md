| 问题 | 修复后的行为 |
| --- | --- |
| 并发删除下标过期 | 历史、收藏、稍后再看共用按 ID 删除的状态管理；重复删除被拦截，刷新不能用旧快照恢复已删除项，失败回滚不会重复插入。 |
| 断网启动假退出 | 凭据状态与个人资料分开保存；同账号可恢复缓存资料；联网、回到前台和手动操作均可重试，明确失效才清理凭据。 |
| 评论分页失败后卡死 | 保留已有评论、页码与“还有下一页”状态，底部显示重试；历史和收藏分页也提供失败重试。 |
| 播放中途错误被隐藏 | 错误优先显示，缓冲状态可见；可重新取流并保留进度；播放源失败时尝试备用地址，重建内核后忽略旧内核事件。 |
| 点赞显示与动作不一致 | 操作读取与显示相同的点赞状态；初次互动关系查询与按钮操作共享加载，迟到的初始快照不会覆盖已完成操作。 |
| 账号切换遗留点赞状态 | 更换会话清空共享差量并更换版本，旧会话回包不能写入新会话；账号所属关注页重建，旧关注请求不能更新新账号的共享状态。 |
| 刷新和旧分页竞争 | 动态刷新、分页及 loading 清理均检查请求版本；旧分页不能覆盖新游标，旧刷新不能清掉新请求的加载状态。 |

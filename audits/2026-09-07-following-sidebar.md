# 关注页侧边头像选择器

按用户草图实现 A/B 两态：默认侧边半露头像，点击展开纵向列表，上下滑动停稳后切换动态，点击外部收起。设置 → 关注页 → 头像列表位置，可选择左侧或右侧，默认左侧并持久保存。

保留动态切换动画、动态卡片长按菜单、UP 主动态缓存和未读标记。展开期间冻结头像顺序，防止已读更新扰动滚动；头像长按仍可打开 UP 主主页。侧边入口位于防误触层之上，收起后不阻挡动态浏览。

## 再次修正重影、单击与连续拖动

用户再次反馈重影，说明之前仅统计滚动容器数量的检查不足。此次同时检查真机渲染图像与单元布局：

- 用 UICollectionView 管理固定行高的头像单元，只变换独立头像宿主，不对滚动容器管理的 contentView 或 SwiftUI 逐行视觉效果进行动画。
- 检查中复现了玻璃对头像的折射副本。最终采用 UIKit UIGlassEffect，头像放在其 contentView 内作为前景，连续轮廓在外层裁切；最终截图未再出现头像副本和错位描边。
- 单击与长按改为独立 UITapGestureRecognizer / UILongPressGestureRecognizer，点击仅等待长按判定失败，不再由 SwiftUI 高优先级序列手势拦截。展开后显式关闭入口触摸层，长按进行中保留同一次触摸。
- 长按按连续手指位移写入同一个 contentOffset，移除取整后逐项 scrollPosition 动画。普通滑动与长按使用同一个松手投影、弹簧停靠流程。
- 真机覆盖四档高度、左右两侧和首/中/末项的 40 次展开；增加单元间距、索引唯一性以及拖动 13pt 必须连续移动 13pt、回拖复位的检查。
- 最终选择器 4 项检查通过；图像证据 `/tmp/neobili-sidebar-mask-screens/`，结果 `/tmp/neobili-sidebar-mask-tests.xcresult`。真实手指触摸未通过远程设备操控验证。
- 版本修订 `following-sidebar-scroll-20260907`。未使用 Device Hub 或 Simulator。

### 伸展时圆角变直角

- 原因是固定凸起轮廓与动态圆角裁切取交集；两条边界相交处会截出硬角。
- 改为单条动态轮廓：圆帽直接以相同切线接入凸起曲线。上下端各自根据实际位置调整，A/B 使用相同路径段数进行插值。
- 在电脑运行抽取实际 Shape 源码的 Swift 检查，93 个中间高度的曲线切线衔接与左右对称性全部通过。Release 真机目标编译通过。

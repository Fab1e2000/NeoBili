# 直播、关注与小窗修复

日期：2026-09-10。此轮用户明确说明手机暂时不在，并禁止 Simulator；没有连接设备或启动模拟器。

## 改动

- 直播页保留推荐、关注和房间链接入口，移除分区选择、分区 API 与官方网页回退。
- 直播卡片复用视频卡片的入场时钟、落位和刷新淡出；提供独立的直播卡片进入/退出设置。
- 小窗渲染交接由播放器主动通知已挂载的容器。更换视频时重新绑定观察者，旧会话和已拆除容器不能抢回新视频画面。保留退出转场结束后才交接的时机。
- 直播间主播名片、关注按钮、完整标题与可展开的简介/公告统一使用玻璃容器；分享移入播放器更多菜单。
- 关注头像下方显示 LIVE，排序为直播、动态更新、其他。直播状态独立分页加载，暂时失败保留已知状态，完整成功后才清理下播状态。
- 长按预览只使用圆形头像和徽标，背景透明。菜单期间暂停滚动及延时切换；菜单退出完成后才导航。

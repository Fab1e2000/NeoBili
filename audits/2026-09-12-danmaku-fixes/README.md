# 弹幕、直播状态与退出转场修复

- 滚动轨道保留所有活动弹幕，不再被后来的弹幕覆盖位置记录；逐帧位置禁止隐式动画，使用真实相对速度判断追尾。固定弹幕暂停期间不消耗剩余时长。
- 系统字体位图按屏幕倍率设置 contentsScale，缓存包含倍率，描边使用字号百分比。
- 直播服务端地址正确解码 wss_port；认证携带当前会话 UID、检查返回码、超时取消连接；兼容旧版用户名位置和多包帧。
- 非全屏弹幕移入详情 ScrollView，与头像关注、简介卡片同级，颜色跟随系统外观。
- 关注头像直播状态改取动态门户 live_users，该数据同时提供 mid 和 room_id；账号登录状态变化触发刷新。
- UIKit 转场期间避免 Metal 子层再启动隐式动画，不将高频位置事件转发到 SwiftUI；媒体解码不停止，转场取消后自然恢复事件。

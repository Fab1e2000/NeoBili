# 彩色弹幕与启动调度

- 彩色弹幕默认开启，设置位于播放与画质页，作用于视频、直播飘幕及直播聊天文字。保留服务端颜色，不随机改色。
- 补齐直播标准 DANMU_MSG 消息头的颜色读取；视频 XML 保留空字段，避免颜色列错位。
- 视频首帧后再加载弹幕，XML 下载和解析通过 @concurrent 明确运行于并发执行器。
- 直播弹幕连接在首帧或 800ms 后启动；房间切换会取消旧等待，不无限等待卡住的视频。原有资料与取流并行路径不变。

验证：generic iOS Debug build-for-testing 通过；iPhone 17 真机 47 项测试全部通过（弹幕 11、直播播放器 20、视频播放器 16）。新增标准消息头颜色、XML 空字段颜色、红色/白色绘制像素回归。未使用 Simulator。

没有采集同源同网络的首帧耗时前后对照；此次只能确认调度和主线程工作量变化，不能量化首帧提速。
